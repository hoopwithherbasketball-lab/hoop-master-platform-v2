# Roku Image Assets

Drop the following image assets into this directory before compiling your BrightScript channel:

1. `splash_fhd.jpg` (1920x1080) - The launch screen for the Roku app.
2. `focus_ring.9.png` - A custom 9-patch image used in `RowListItem.xml` to draw the `#fb6c1d` focus border around selected videos.
