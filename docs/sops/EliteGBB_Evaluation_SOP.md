# EliteGBB Standard Operating Procedure: Evaluations & Intake

## 1. Purpose
This SOP standardizes the process for collecting intake submissions, grading athletes in the EliteGBB platform, and logging game stats. Adhering to these standards ensures the searchable dashboard provides accurate and filterable insights for recruiters and scouts.

## 2. Intake Submissions (Parent/Athlete)
When athletes or parents submit an intake form:
- **Position Mapping**: Always map positions to standardized acronyms (PG, SG, SF, PF, C). Do not use variations like "Point Guard" or "1".
- **Class Year**: Must be a 4-digit year (e.g., "2026", "2027"). 
- **State**: Use the 2-letter postal abbreviation (e.g., "NC", "SC", "GA").

## 3. Coach Evaluations
When a coach evaluates a player post-event:
- **Numerical Scoring (0-10)**: 
  - 9-10: Elite / High-Major D1 Ready
  - 7-8: Mid-Major D1 Ready
  - 5-6: D2/D3/NAIA Contributor
  - Below 5: Needs Significant Development
- **Overall Grade vs. Recommendation**: Ensure the overall grade matches the recommendation. Do not grade a player 'C' and recommend 'offer'.
- **Privacy Note for Minors**: Evaluation notes are strictly internal. Do not include personal phone numbers or direct contacts in the raw evaluation text fields.

## 4. Game Stats
- **Opponent Naming**: Use the full high school or AAU program name to allow for historical matching.
- **Verification**: If game stats seem anomalous (e.g., 50+ points), cross-reference with film before finalizing the record.

*Note: As the platform evolves, the admin dashboard will automatically enforce many of these rules via dropdowns.*
